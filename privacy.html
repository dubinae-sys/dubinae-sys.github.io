개인정보처리방침

앱 이름: daum-gmail-bridge
시행일: 2026년 9월 9일

1. 운영 목적

운영자 본인의 Daum 메일을 본인의 Gmail로 복사하는 개인용 자동화 도구입니다. 일반 사용자의 가입을 받지 않습니다.

2. 접근하는 정보와 이용 목적

Daum 메일의 발신자, 수신자, 제목, 본문, 첨부파일 및 메일 식별정보를 읽어 Gmail에 저장합니다. Google OAuth로 Gmail 접근 권한(gmail.modify)을 받아 중복 메일 확인과 메일 저장에 사용합니다. 인증 확인 시 Gmail 계정 이메일 주소를 확인합니다.

3. 처리 및 보관

자동화는 GitHub Actions에서 실행됩니다. 메일 내용은 실행 중 처리되며 복사된 메일은 Gmail에 보관됩니다. 인증정보는 비공개 저장소의 GitHub Actions Secrets에 저장합니다. 동기화 진행정보는 비공개 저장소에 보관하며, 실행 기록에는 메일 식별정보와 처리 결과가 포함될 수 있습니다. 메일 본문과 첨부파일은 공개 홈페이지나 공개 저장소에 게시하지 않습니다.

4. 정보 제공과 이용 제한

메일 동기화에 필요한 범위에서 Daum, Google 및 실행 기반인 GitHub 서비스를 이용합니다. 이 앱은 메일 정보를 판매하거나 광고, 사용자 추적, AI 모델 학습 목적으로 이용하지 않습니다.

Google API로 받은 정보의 이용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 접근 해제와 삭제

운영자는 Google 계정의 연결된 앱 관리에서 접근 권한을 철회하고 GitHub Actions 실행을 중지할 수 있습니다. 저장된 인증정보, 실행 기록 및 동기화 진행정보는 GitHub에서 삭제할 수 있습니다. Gmail에 복사된 메일은 Gmail에서 직접 삭제할 수 있으며, 접근 권한 철회만으로 기존 메일이 삭제되지는 않습니다.
